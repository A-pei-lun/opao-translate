# O泡翻译源码

版本 0.1.3，采用浏览器扩展内的本地组件和用户配置 API。

0.1.3 加入独立排队的3秒超时切换提醒、本地持久诊断日志与页面筛选，扩大普通双语扫描到导航和底部，处理含控件容器的文字与链接裁剪。日志通过字段白名单写入本地存储，最多1000条、有效期7天。

0.1.2 完善自定义服务名称的即时联动，接口模板保留自定义名称。新增默认关闭的超时自动切换及备用顺序设置，成功服务只记忆在当前内容文档，导航与刷新后重置。超时直接进入下一服务，其他错误维持原重试逻辑。

0.1.1 增加浮球拖动/贴边半隐、页内服务选择、完整段落纵向对照、8 种共用样式和自定义译文字体。浮球位置使用独立本地键保存，页面外观更新与模型任务分开处理。

## 模块

| 路径 | 责任 |
| --- | --- |
| src/background.js | 设置隔离、页面分派、菜单、图片请求与捕获入口 |
| src/runtime.js | offscreen 请求与持续任务 |
| src/engine | 多协议、队列、取消、缓存和音频捕获 |
| src/content | 网页段落、富文本、划词、输入、图片和字幕 |
| src/content/floating.js | 拖动、贴边收起、悬停与位置记忆 |
| src/content/paragraphs.js | 完整逻辑段落、内联内容合并与双换行分段 |
| src/shared/appearance.js | 实际页面与设置预览共用的样式、字体与位置格式 |
| src/shared/failover.js | 页面内的超时识别、并发探测、按序切换、取消和选择重置 |
| src/shared/diagnostics.js | 串行持久诊断、元数据筛选、页面查询与容量限制 |
| src/tools | PDF、EPUB、HTML、编码和音频解码 |
| src/shared | 配置、语言、消息、文本、图片和字幕格式 |
| src/settings.js | 设置页面 |
| src/popup.js | 扩展弹窗 |
| src/workspace.js | 本地翻译工作台 |
| public | 页面、样式、图标、748 条提取规则与安装说明 |
| tests | 核心回归、本地模拟接口与 Edge 集成验证 |

站点提取数据和 132 个语言选项由用户提供包的静态数据整理而来。构建直接读取本源码目录中的资源。第三方组件按 package-lock.json 固定版本。

## 构建

在此目录运行以下 PowerShell 命令。开发验证使用 Node 24.16.0。

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd test
npm.cmd run build
```

输出到上一级项目的 05_构建产物/O泡翻译-0.1.3，并生成 ZIP 与文件指纹清单。构建脚本只清理已校验的同版本构建目录。

在本项目中由代理执行的读写、构建和测试，统一通过根目录 90_日志/脚本/Invoke-ProjectOperation.ps1 记录到项目总日志。

## Edge 集成验证

```powershell
npm.cmd run test:browser
```

验证脚本使用已安装的 Microsoft Edge，创建专用测试配置和临时环回模拟接口，输出到上一级 04_验证/0.1.3/Edge端到端。测试结束后关闭浏览器和模拟接口。配置目录带归属标记，复用前进行路径校验。

模拟响应主要验证请求协议、消息传递、页面状态、绘制与文件结构。真实模型与真实网站的效果单独记录。

跨版本升级验收可运行 `node tests/upgrade.mjs`，需要上级构建目录中已有 0.1.2 和当前版本。它使用独立测试配置及模拟凭据，按重新加载扩展的流程检查数据延续。

自动切换回归位于 `tests/failover.test.mjs`，包含禁用默认值、排序迁移、兼容性过滤、状态复用、并发切换、取消和导航重置。Edge 夹具另外使用真实 5 秒等待及受控 504/401 响应检查整条消息链。

## 关键实现边界

- 密钥由扩展内部处理，发往内容脚本的服务数据经过字段筛选。
- 网页富文本使用受保护标记，校验模型返回的标记完整性并安全克隆原节点。
- 接口支持自动补全及完整地址模式，无密钥接口可直接发现模型。
- 图片采用视觉识别与本地覆盖绘制。PDF 译页使用图像，常规双语 PDF 保留原页文字层。
- 语音走用户自己的 OpenAI 兼容转录接口。隐私遮蔽走本地可编辑规则。
- 稳定公钥身份随版本保留，便于自用更新和配置延续。
- 页面自动切换只对翻译生效，文字和视觉按能力及场景主服务分别记忆。对照模型、写作、语音识别及工作台文件任务不加入网页自动切换链。
