# O泡翻译源码

版本 0.1.9，采用浏览器扩展内的本地组件和用户配置 API。

0.1.9 修复批量翻译漏项放大成整页报错的问题。有效译文独立校验和显示，仅对缺项或校验失败项缩批补译，最后一次逐段发送。长段重试复用有效缓存，终态错误只显示在对应段落。本地诊断包含预期与实际 ID、失败原因和脱敏响应结构。

0.1.8 重排全部五个设置分类：服务基础配置前置，高级请求参数与 JSON 配置折叠；阅读设置分为语言、译文外观、交互、AI 排版和划词服务；媒体、站点与数据按用途分组。统一标签、说明、控件与开关对齐，保留实时预览，支持分类直达地址、键盘跳转、未保存离开提醒与清空/删除确认。设置页使用独立的 public/settings.css，翻译引擎和共享弹窗/工作台样式保持原文件。通过79项单元、45项完整Edge、11项设置专项及0.1.7到0.1.8升级验证；设置专项覆盖320～1360px与浅色/深色/系统主题。全部为隔离Edge及本地模拟接口，真实用户服务未调用。

0.1.7 新增默认关闭的实验性 AI 排版及下级“发送完整网页 HTML”开关，可单独选择排版服务。排版队列独立于网页翻译，最多执行一个排版请求，并与其他请求共享服务/总体并发上限。模型仅返回受支持的显示方式，不生成可执行网页代码。默认传入结构、尺寸和区域文本；完整 HTML 开启时清理脚本、表单值及插件界面，超过200万字符时回退到本地布局。现有隐私遮蔽继续生效。

修正双语重复图标、富文本布局样式继承、固定顶栏的纵向 gap 和窄导航布局。默认每服务4并发、每批8段、总体5请求；页面送批按吞吐计算，批次通过格式校验后立即发布已完成段落。旧默认3并发/5段组合一次性升级，其他自定义值保留。169项自动检查通过；Fandom实站访问被403拦截，真实模型未调用，实站与真实AI排版效果尚未验收。

0.1.6.2 基于 Opus UI 优化版 0.1.6.1，修复网页双语强制开启流式：服务中的“使用流式输出”关闭时，等待完整译文再显示；开启时，网页双语随流式响应逐步显示。切换备用服务后遵循备用服务自己的开关。下述 0.1.6 验证记录为历史结果。

0.1.6 修复 X 旧规则跳过导航、侧栏、标题与元信息的问题，并补齐根节点自身匹配时的扫描。目标为简体中文时自动跳过简体为主的段落，允许夹杂英文专名。“阅读与交互”新增默认关闭的“繁体中文转简体后替换原文”：开启后通过固定版本 OpenCC 在本地整段转换，再写回原文本节点，保留链接、格式与事件，支持恢复。代码、输入内容和站点保护区不参与转换。AI判断某段是否值得翻译仅完成论证，没有实现。

0.1.5 增加网页流式译文：生成时在对应段落逐步显示纯文字预览；校验完成后用120ms淡出临时文字，再以220ms淡入与轻微上移呈现最终富文本，并过渡高度。内部JSON、段落ID与格式标记不显示。当前网页对Chat/Responses/Claude/Gemini遵循服务中的流式开关；传统翻译、缓存命中或返回普通JSON的服务直接显示完整结果。其他场景保留已有服务配置。

0.1.4 修复 Steam 等页面首尾或孤立 br 导致 nodeType 空值错误、中断页面扫描的问题，避免已选中的块标题被再次包装而漏译。导航文字行在翻译期间放开固定高度，限制长译文宽度，保留侧栏滚动；支持语义导航及 data-sidebar 容器、动态菜单、纯译文和大字号。恢复时按扩展持有的样式属性回滚，保留网站随后修改的属性。

0.1.3 加入独立排队的3秒超时切换提醒、本地持久诊断日志与页面筛选，扩大普通双语扫描到导航和底部，处理含控件容器的文字与链接裁剪。日志通过字段白名单写入本地存储，最多1000条、有效期7天。

0.1.2 完善自定义服务名称的即时联动，接口模板保留自定义名称。新增默认关闭的超时自动切换及备用顺序设置，成功服务只记忆在当前内容文档，导航与刷新后重置。超时直接进入下一服务，其他错误维持原重试逻辑。

0.1.1 增加浮球拖动/贴边半隐、页内服务选择、完整段落纵向对照、8 种共用样式和自定义译文字体。浮球位置使用独立本地键保存，页面外观更新与模型任务分开处理。

## 模块

| 路径 | 责任 |
| --- | --- |
| src/background.js | 设置隔离、页面分派、菜单、图片请求与捕获入口 |
| src/runtime.js | offscreen 请求与持续任务 |
| src/engine | 多协议、队列、取消、缓存和音频捕获 |
| src/content | 网页段落、富文本、划词、输入、图片和字幕 |
| src/content/floating.js | 拖动、贴边收起、悬停与位置记忆 |
| src/content/paragraphs.js | 完整逻辑段落、内联内容合并与双换行分段 |
| src/content/stream-view.js | 流式预览、最终排版动画和取消后的延迟写入清理 |
| src/content/layout.js | 独立排版队列、页面结构/HTML整理和布局结果应用 |
| src/shared/layout.js | 排版输入与模型决策契约、允许的显示方式 |
| src/shared/appearance.js | 实际页面与设置预览共用的样式、字体与位置格式 |
| src/shared/failover.js | 页面内的超时识别、并发探测、按序切换、取消和选择重置 |
| src/shared/diagnostics.js | 串行持久诊断、元数据筛选、页面查询与容量限制 |
| src/shared/streaming.js | 增量JSON字符串提取与内部保护标记隐藏 |
| src/tools | PDF、EPUB、HTML、编码和音频解码 |
| src/shared | 配置、语言、消息、文本、图片和字幕格式 |
| src/settings.js | 设置页面 |
| src/popup.js | 扩展弹窗 |
| src/workspace.js | 本地翻译工作台 |
| public | 页面、样式、图标、748 条提取规则与安装说明 |
| tests | 核心回归、本地模拟接口与 Edge 集成验证 |

站点提取数据和 132 个语言选项由用户提供包的静态数据整理而来。构建直接读取本源码目录中的资源。第三方组件按 package-lock.json 固定版本。

## 构建

在此目录运行以下 PowerShell 命令。开发验证使用 Node 24.16.0。

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd test
npm.cmd run build
```

输出到上一级项目的 05_构建产物/O泡翻译-0.1.9，并生成 ZIP 与文件指纹清单。构建脚本只清理已校验的同版本构建目录。

在本项目中由代理执行的读写、构建和测试，统一通过根目录 90_日志/脚本/Invoke-ProjectOperation.ps1 记录到项目总日志。

## Edge 集成验证

```powershell
npm.cmd run test:browser
npm.cmd run test:ai-layout
```

验证脚本使用已安装的 Microsoft Edge，创建专用测试配置和临时环回模拟接口，输出到上一级 04_验证/0.1.9 对应目录。测试结束后关闭浏览器和模拟接口。配置目录带归属标记，复用前进行路径校验。设置页专项运行 npm.cmd run test:settings。

模拟响应主要验证请求协议、消息传递、页面状态、绘制与文件结构。真实模型与真实网站的效果单独记录。

Steam 与固定行高侧栏的回归运行 `npm.cmd run test:layout`，结果位于 `04_验证/0.1.6/布局回归/0.1.6`。运行 `node tests/layout.mjs 0.1.3` 可对历史构建运行同样断言，保留修复前失败证据。夹具覆盖首尾/孤立/带注释的换行、工坊描述、固定行高菜单、动态项目、字体设置、滚动和样式恢复。原始登录态网站及真实模型输出需要另行复验。

流式专项运行 `npm.cmd run test:stream`，结果位于 `04_验证/0.1.6/流式Edge`。本地服务分时发送真正的SSE事件，验证网络完成前文字增长、动画顺序、最终链接/强调、减少动画偏好、普通JSON回退、生成中/淡出时恢复、保护标记无效、流式失败、超时切换和缓存。核心用例另覆盖UTF-8/JSON转义、并发段落归属、乱序片段与过期任务消息。

跨版本升级验收可运行 `node tests/upgrade.mjs`，需要上级构建目录中已有 0.1.5 和当前版本。它使用独立测试配置及模拟凭据，按重新加载扩展的流程检查数据延续。

自动切换回归位于 `tests/failover.test.mjs`，包含禁用默认值、排序迁移、兼容性过滤、状态复用、并发切换、取消和导航重置。Edge 夹具另外使用真实 5 秒等待及受控 504/401 响应检查整条消息链。

## 关键实现边界

- 密钥由扩展内部处理，发往内容脚本的服务数据经过字段筛选。
- 网页富文本使用受保护标记，校验模型返回的标记完整性并安全克隆原节点。
- 接口支持自动补全及完整地址模式，无密钥接口可直接发现模型。
- 图片采用视觉识别与本地覆盖绘制。PDF 译页使用图像，常规双语 PDF 保留原页文字层。
- 语音走用户自己的 OpenAI 兼容转录接口。隐私遮蔽走本地可编辑规则。
- 稳定公钥身份随版本保留，便于自用更新和配置延续。
- 页面自动切换只对翻译生效，文字和视觉按能力及场景主服务分别记忆。对照模型、写作、语音识别及工作台文件任务不加入网页自动切换链。
- 网页增量以任务、请求尝试、段落和递增序号区分；失败重试或换服务时清理临时文字，恢复时取消动画与定时器。最终富文本继续经过完整格式和隐私标记校验；预览仅用textContent写入。
- 流式降低首段可见等待，不保证降低上游总耗时。模型未输出文本前仍需等待；上游若缓冲全部输出，客户端无法提前显示。系统减少动画偏好会跳过淡出/淡入，保留流式文字增长。

漏译与中文专项运行 `npm.cmd run test:coverage`，检查实际x.com规则下的本地DOM夹具、中文跳过、繁体整段转换、开关保存、链接/输入保护和恢复。结果位于 `04_验证/0.1.6/漏译与中文回归`。使用 `node tests/coverage.mjs 0.1.5` 可复现旧版失败。真实登录态X和模型输出未现场验证。
