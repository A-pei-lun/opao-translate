# O泡翻译 0.1.7

个人自用 Edge 扩展。模型、密钥与场景分配通过本地设置页管理，界面支持系统、浅色和深色主题。

## 0.1.7 更新

- “阅读与交互”新增实验性“AI排版”，默认关闭。开启后，模型为已翻译区域选择上下双语、紧凑双语、行内对照或原位替换；翻译继续进行，排版失败时保留本地布局。
- “发送完整网页 HTML”是“AI排版”的下级开关，默认关闭，主开关关闭时不可操作。默认仅发送待排版区域的原文、译文、结构与尺寸；开启后发送清除脚本、表单值及插件界面的整页 HTML，可能增加耗时和用量。
- 排版服务默认跟随网页与文本服务，也可单独选择 Chat Completions、Responses、Claude 或 Gemini 服务。传统翻译接口不能承担 AI 排版。现有隐私遮蔽设置同样作用于排版请求。
- 修复双语译文重复图标、富文本子节点继承原布局样式导致异常空白，以及固定顶栏和窄侧栏的间距问题。恢复原文时还原扩展修改的布局属性。
- 默认每服务并发由 3 提至 4，每批由 5 段提至 8 段，总体请求上限由 4 提至 5。网页按服务吞吐扩大送批，单个接口批次校验完成即可显示完整译文，关闭 AI 排版也能受益。
- 从旧版本升级时，仅旧默认“3并发/5段”组合自动升级一次；其他自定义组合保留。之后手动设回 3/5 不会再次被改写。

本版通过 169 项自动检查，其中包括 79 项单元、89 项隔离 Edge 和 1 项升级检查。80 段本地模拟接口对比由 1421 ms 降至 535 ms；这不是对真实服务速度的保证。真实模型接口未调用；Fandom 实站被 403 验证页拦截，尚未现场验收真实页面效果。

## 0.1.6.2 更新

- 基于 Opus UI 优化版 0.1.6.1，保留其界面。
- 网页双语不再强制开启流式，遵循所选服务的“使用流式输出”开关。关闭时等完整译文返回再显示；开启时，支持流式的服务才逐步显示译文。
- 划词、文档等文本翻译继续使用同一服务配置；切换备用服务后使用备用服务自己的流式开关。缓存命中时直接显示已有完整译文。
- 本次不代表修复服务商的HTTP 502或接口格式问题。若服务只有Chat非流式可用，请选择Chat协议并关闭该服务的流式输出。

## 0.1.6 更新

- 修复 X 导航、侧栏标题、底部条款、时间信息、排序、查看引用和回复占位文字漏译；输入内容保持排除。
- 目标为简体中文时，已是简体为主的段落自动跳过，允许夹杂 ChatGPT、Google Play、API 等英文名称。
- “阅读与交互”新增“繁体中文转简体后替换原文”，默认关闭。开启后在本地整段转简体并显示一份内容，保留链接与格式，可恢复原文；关闭时仍按默认阅读模式翻译繁体。
- 目标改为英语或繁体等语言后，继续按所选目标翻译。繁简转换不负责粤语、文言改写，也不全面替换地区用语。

使用独立 Edge 与本机模拟接口验证。真实登录态 X 与真实模型效果未现场验收；复杂混合语种、无语言标注的纯汉字短句可能判错。AI判断翻译必要性仅作论证，没有实现。

## 0.1.5 保留改进

- 网页译文现在随接口返回逐步显示，内部 JSON、段落编号与格式标记不直接显示。
- 整组结果完成且通过格式校验后，临时译文淡出，带链接、加粗等格式的正式译文整体淡入并轻微上移；高度随排版过渡。
- 当前网页使用 Chat Completions、Responses、Claude 或 Gemini 时，由服务中的“使用流式输出”决定是否请求流式。传统翻译、缓存命中或上游只返回完整 JSON 时直接显示最终结果。
- 取消、恢复原文、网页导航和服务切换会停止或清理旧预览，防止旧请求把文字写回来。流式失败或格式标记无效时显示错误与重试入口。
- 跟随系统“减少动画”偏好：跳过淡出淡入，仍逐步显示文字。

临时预览为纯文字，链接等格式在最终排版时出现。首字出现时间受模型和中转站影响；尚无文字输出或中转站缓冲结果时，页面仍会等待。本版使用隔离 Edge 与本机分时 SSE 接口验证，真实用户服务未由代理调用。

## 0.1.2 保留改进

- “服务与模型”的“自定义服务名称”可以填写中转站名称或用途。改名即时更新配置列表、场景下拉框及备用列表，保存后同步到页内选择。接口模板保留已经填写的自定义名称。
- 新增“服务超时后自动切换”，默认关闭。在“超时自动切换”列表中用“上移”“下移”安排备用服务，点击“保存设置”生效。
- 开启后先使用当前场景或翻译框选定的服务，本地超时或 HTTP 408、504 后按列表顺序尝试其余兼容服务。超时直接尝试下一项，不先重复等待当前服务的失败重试。
- 成功后同一页的后续翻译使用该可用服务，页内设置会显示实际服务。默认场景不会被自动切换改写，刷新、进入其他页面、单页应用 URL 变化或修改翻译服务设置会重置。
- 未启用、未配置或能力不符的备用项会跳过。本页同一条链中的所有候选均超时后停止继续尝试，可刷新或手动换服务重试。
- 网页、划词、输入和字幕的文本翻译共用对应场景主服务的选择链。图片单独选择支持视觉的服务，多模型对照、写作、语音识别和工作台文件任务继续按其指定服务执行。
- 鉴权错误、限流、返回格式错误、普通网络错误和主动取消不会触发自动切换。开启后，多服务依次等待的总耗时可能增加，可按需调低各服务的“超时，秒”。

## 从旧版升级

1. 在旧版设置中导出配置作为回退。
2. 解压 0.1.6.2 到你的扩展安装位置。固定目录可覆盖旧文件，变更目录时在 Edge 加载新文件夹。
3. 到 `edge://extensions` 确认 O泡翻译条目的版本为 0.1.6.2，并点击该条目的“重新加载”。
4. 刷新需要翻译的网页，让内容脚本更新。

0.1.5 到 0.1.6 的升级验收使用同一隔离浏览器配置，检查服务名称、模拟密钥和既有样式延续。扩展公钥与配置结构保持兼容。重新加载步骤用于更新浏览器保留的后台脚本。

## 安装

1. 解压 O泡翻译-0.1.7.zip。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压后含有 manifest.json 的文件夹。
5. 点击 O泡翻译图标，再进入“设置”。

自用扩展 ID 为 `algfmboniibmkmffjhncpnnahiccpbcj`。更新版本时保留源码中的公钥身份，重新加载扩展后刷新要翻译的网页。

## 配置文本模型

在“服务与模型”添加或编辑一个服务。

| 字段 | 填写方法 |
| --- | --- |
| 接口协议 | 按服务选择 Chat Completions、Responses、Claude、Gemini 或传统翻译接口 |
| API 地址 | 可填根地址、版本路径或标准完整接口地址 |
| 端点路径处理 | 非标准完整路径使用“按完整地址原样请求” |
| API Key | 填入自己的密钥，无鉴权接口可留空 |
| 模型 ID | 手动填写，或通过“获取模型列表”选择 |
| 接口能力 | 根据实际模型勾选文本、视觉或语音 |

先点击“测试文字连通”，再将服务分配给“网页与文本”。最后点击“保存设置”。模型列表、文字、视觉和语音是不同能力，需要分别验证。

可以为同一 API 地址建立多个服务，分别填写文本、视觉和语音模型。可用模型由你的接口决定。

## 配置图片模型

建立视觉服务，填写支持图片输入的模型并勾选“视觉输入”，再把它分配给“图片识别与翻译”。

- 网页图片可以通过右键“翻译这张图片”处理，再次翻译同一张图可恢复原图。
- 弹窗的“图片与漫画”可以批量处理网页图片。
- 工作台支持多选、拖放或粘贴图片，长图自动分片，结果可保存为 PNG 或批量 ZIP。
- 当前绘制方式为采样底色或半透明覆盖，译文位置来自视觉模型返回的区域坐标。

## 网页、划词与输入

| 操作 | 入口 |
| --- | --- |
| 网页双语 | 浮动 O 按钮、弹窗、右键或 Alt+A |
| 整页翻译 | 弹窗、右键或 Alt+W |
| 恢复原文 | 弹窗“恢复原文”，或再次切换网页翻译 |
| 纯译文 | 弹窗“纯译文” |
| 划词翻译 | 选中文字后的“译”按钮或右键 |
| 多模型对照 | 选中文字后右键选择，服务在设置中指定 |
| 悬停翻译 | 按住设置中的 Alt、Ctrl 或 Shift 后悬停 |
| 输入框翻译 | 聚焦输入框后 Alt+I，或通过右键操作 |
| 写作与改写 | 输入框/选区右键，或工作台“写作” |
| 工作台侧栏 | Alt+S 或弹窗“打开侧栏” |

输入框译文可预览后回填。默认输入目标语言为英语，可以在“阅读与交互”调整。快捷键可在 `edge://extensions/shortcuts` 修改。

## 文档与字幕文件

工作台的“文档”支持 PDF、EPUB、TXT 和 HTML。

- PDF 支持本地或在线文件、文字层翻译、扫描页视觉处理、单页或整本双语导出。
- PDF 译页以图像保存，普通 PDF 的双语导出保留原页文字层。复杂公式、多栏和专业排版效果需要用实际文件检查。
- EPUB 支持章节阅读、逐章/整本翻译和重新打包，保留书内资源及尚未翻译的章节。
- TXT 和 HTML 支持浏览器内翻译与导出。HTML 预览会清理可执行内容。
- 字幕工具支持 SRT、VTT、ASS，保留时间轴与 ASS 样式，可逐条编辑译文后导出。

切换目标语言或服务会清理当前工具的旧翻译结果，原始文件继续保留在工作区。

## 视频、会议与音频

使用弹窗或右键开启“双语字幕”，播放器应先提供字幕轨道或可见字幕。自定义网站字幕选择器可在“图片与字幕”填写。可开启未来 90 秒预翻译，并导出双语 SRT。

无字幕音频使用自己的转录 API。

1. 新建服务，选择“OpenAI 兼容语音识别”协议，填写转录模型和地址。
2. 勾选语音能力并分配给“语音识别”。
3. 按服务能力设置 JSON、带时间戳 JSON、SRT 或 VTT 等响应格式。
4. 本地音视频在工作台选择文件后识别。页面音频从弹窗或右键启动，再次操作可停止。

模型返回精确分段时间戳时保留对应时间轴，纯文字响应按录音片段定位。语音服务和文字翻译服务可以分别选择。

## 数据管理

配置、术语和规则保存在扩展本地。默认配置导出会移除密钥和常见认证字段，也可以主动选择包含密钥。旧版 JSON 配置可导入，旧版加密密钥需要重新填写。

隐私遮蔽使用本地邮箱、长数字及自定义正则规则，在发送文本前替换并在译文中恢复。缓存可设置有效期、条目数量并随时清空。诊断记录提供服务、操作、耗时和脱敏错误摘要。

## 验证范围

已使用隔离 Microsoft Edge 和本地模拟接口验证主要入口及导出链路。真实模型质量、全部视频/会议网站、原生右键菜单实际点击和实时页面音频捕获仍需结合实际使用复核。

第三方 API 调用按所选服务计费。第三方库许可保存在 THIRD_PARTY_NOTICES.txt 及随包许可文件中。
