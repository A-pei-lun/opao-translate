# O泡翻译 0.1.0

个人自用 Edge 扩展。模型、密钥与场景分配通过本地设置页管理，界面支持系统、浅色和深色主题。

## 安装

1. 解压 O泡翻译-0.1.0.zip。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压后含有 manifest.json 的文件夹。
5. 点击 O泡翻译图标，再进入“设置”。

自用扩展 ID 为 `algfmboniibmkmffjhncpnnahiccpbcj`。更新版本时保留源码中的公钥身份，重新加载扩展后刷新要翻译的网页。

## 配置文本模型

在“服务与模型”添加或编辑一个服务。

| 字段 | 填写方法 |
| --- | --- |
| 接口协议 | 按服务选择 Chat Completions、Responses、Claude、Gemini 或传统翻译接口 |
| API 地址 | 可填根地址、版本路径或标准完整接口地址 |
| 端点路径处理 | 非标准完整路径使用“按完整地址原样请求” |
| API Key | 填入自己的密钥，无鉴权接口可留空 |
| 模型 ID | 手动填写，或通过“获取模型列表”选择 |
| 接口能力 | 根据实际模型勾选文本、视觉或语音 |

先点击“测试文字连通”，再将服务分配给“网页与文本”。最后点击“保存设置”。模型列表、文字、视觉和语音是不同能力，需要分别验证。

可以为同一 API 地址建立多个服务，分别填写文本、视觉和语音模型。可用模型由你的接口决定。

## 配置图片模型

建立视觉服务，填写支持图片输入的模型并勾选“视觉输入”，再把它分配给“图片识别与翻译”。

- 网页图片可以通过右键“翻译这张图片”处理，再次翻译同一张图可恢复原图。
- 弹窗的“图片与漫画”可以批量处理网页图片。
- 工作台支持多选、拖放或粘贴图片，长图自动分片，结果可保存为 PNG 或批量 ZIP。
- 当前绘制方式为采样底色或半透明覆盖，译文位置来自视觉模型返回的区域坐标。

## 网页、划词与输入

| 操作 | 入口 |
| --- | --- |
| 网页双语 | 浮动 O 按钮、弹窗、右键或 Alt+A |
| 整页翻译 | 弹窗、右键或 Alt+W |
| 恢复原文 | 弹窗“恢复原文”，或再次切换网页翻译 |
| 纯译文 | 弹窗“纯译文” |
| 划词翻译 | 选中文字后的“译”按钮或右键 |
| 多模型对照 | 选中文字后右键选择，服务在设置中指定 |
| 悬停翻译 | 按住设置中的 Alt、Ctrl 或 Shift 后悬停 |
| 输入框翻译 | 聚焦输入框后 Alt+I，或通过右键操作 |
| 写作与改写 | 输入框/选区右键，或工作台“写作” |
| 工作台侧栏 | Alt+S 或弹窗“打开侧栏” |

输入框译文可预览后回填。默认输入目标语言为英语，可以在“阅读与交互”调整。快捷键可在 `edge://extensions/shortcuts` 修改。

## 文档与字幕文件

工作台的“文档”支持 PDF、EPUB、TXT 和 HTML。

- PDF 支持本地或在线文件、文字层翻译、扫描页视觉处理、单页或整本双语导出。
- PDF 译页以图像保存，普通 PDF 的双语导出保留原页文字层。复杂公式、多栏和专业排版效果需要用实际文件检查。
- EPUB 支持章节阅读、逐章/整本翻译和重新打包，保留书内资源及尚未翻译的章节。
- TXT 和 HTML 支持浏览器内翻译与导出。HTML 预览会清理可执行内容。
- 字幕工具支持 SRT、VTT、ASS，保留时间轴与 ASS 样式，可逐条编辑译文后导出。

切换目标语言或服务会清理当前工具的旧翻译结果，原始文件继续保留在工作区。

## 视频、会议与音频

使用弹窗或右键开启“双语字幕”，播放器应先提供字幕轨道或可见字幕。自定义网站字幕选择器可在“图片与字幕”填写。可开启未来 90 秒预翻译，并导出双语 SRT。

无字幕音频使用自己的转录 API。

1. 新建服务，选择“OpenAI 兼容语音识别”协议，填写转录模型和地址。
2. 勾选语音能力并分配给“语音识别”。
3. 按服务能力设置 JSON、带时间戳 JSON、SRT 或 VTT 等响应格式。
4. 本地音视频在工作台选择文件后识别。页面音频从弹窗或右键启动，再次操作可停止。

模型返回精确分段时间戳时保留对应时间轴，纯文字响应按录音片段定位。语音服务和文字翻译服务可以分别选择。

## 数据管理

配置、术语和规则保存在扩展本地。默认配置导出会移除密钥和常见认证字段，也可以主动选择包含密钥。旧版 JSON 配置可导入，旧版加密密钥需要重新填写。

隐私遮蔽使用本地邮箱、长数字及自定义正则规则，在发送文本前替换并在译文中恢复。缓存可设置有效期、条目数量并随时清空。诊断记录提供服务、操作、耗时和脱敏错误摘要。

## 验证范围

已使用隔离 Microsoft Edge 和本地模拟接口验证主要入口及导出链路。真实模型质量、全部视频/会议网站、原生右键菜单实际点击和实时页面音频捕获仍需结合实际使用复核。

第三方 API 调用按所选服务计费。第三方库许可保存在 THIRD_PARTY_NOTICES.txt 及随包许可文件中。
